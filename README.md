# Weather Report App

A beginner-friendly weather app built with HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Current temperature and feels-like temperature
- Weather condition with an emoji
- Humidity and wind speed
- Responsive design for phones and computers
- Uses Open-Meteo's free geocoding and forecast APIs; no API key required for this example

## How to run
1. Download or clone this folder.
2. Open `index.html` in a modern browser.
3. Make sure you are connected to the internet so the weather API can load.

If your browser blocks API requests when opening the file directly, open the folder in Visual Studio Code and use the Live Server extension.

## Files
- `index.html` — page structure
- `style.css` — design
- `script.js` — city search and weather API requests

## Data source
Weather data: https://open-meteo.com/
